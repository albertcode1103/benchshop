# 工作台仪表盘实施记录

状态：本机实现并隔离验证，已纳入 2026-09-13 本次 Git 版本；尚未发布 NAS。

## 界面与信息流

- 管理员和业务员默认进入仪表盘；合法的指定页面链接优先。侧栏仍使用“概览”入口。
- 按待办摘要、重点处理、7/30天新增趋势、近期业务、目录与分享、管理员账号及操作动态排列。桌面重点处理区为3:2双列，平板及手机单列，待办卡片小屏两列。
- 四项待办：待跟进询价、报价草稿、3天未更新询价、7天内到期报价。卡片进入明确筛选后的列表，清除旧搜索及状态并回到第一页。
- 趋势默认30天，支持7天；按创建时间统计单据，以北京时间自然日分组，包含今天、缺失日补零。图表可点选日期，也可使用键盘操作日期选择器查看准确数值。
- 每类摘要最多5条。询价按最久未更新优先、草稿按最近修改、到期报价按到期时间排序；近期询价/分享按创建时间、近期报价按更新时间排序。
- 设备、配置、工具、附件展示启用数/总数；有效分享和浏览量为全局当前有效数及历史累计浏览，不展示推算的浏览趋势、销售额或成交率。
- 仪表盘数据与列表分页、筛选状态独立。进入、手动刷新及相关写入后更新；无自动轮询。加载失败不伪装成零，保留旧数据时标明更新失败。旧API返回404时提示需要先发布兼容接口。
- 有效分享复用现有配置预览；已关闭/过期分享只展示记录摘要并禁用导出/报价。报价复用编辑器，归档报价打开现有版本与发送历史。

## 接口与口径

新增 `GET /api/v1/staff/dashboard?days=7|30`。只读、仅管理员/业务员；服务端从登录账号确定范围，不允许传入其他用户ID切换个人口径。

响应包括 `generated_at`、`days`、`timezone`、`scopes`、`counts`、`tasks`、`trend`、`recent`、`catalog`、`shares`；仅管理员包含 `admin` 账号统计与审计摘要。

- 管理员待办包含未分配询价，报价为全部报价。业务员待办仅限分配给自己的询价，报价仅限本人。
- 近期询价、分享及对应趋势仍为现有公共业务池；页面明确标注“公共”。不改变分配、编辑、发送、恢复等业务权限。
- 询价列表与仪表盘复用同一派生状态SQL；只将 `new/assigned/contacted` 计入待跟进。存在报价草稿、已发送报价或已关闭/取消的询价不重复列入。
- 未更新提醒按 `updated_at`、缺失时按 `created_at`，严格超过72小时。不是自动关单或工作流状态。
- 到期提醒仅统计当前已发送报价，截止时刻必须晚于现在且不晚于现在加7天。日期型有效期包含北京时间当天整日；带时区时间按精确时刻处理，无时区数据库时间按UTC解释；无有效期不计入。
- 分享合并旧配置分享与新混合分享；有效状态同时检查启用及到期时间。报价合并新旧单据，修订表不参与数量累计。
- 目录不计已删除条目；启用数同时检查条目及所属分类启用状态。账号不计游客和已归档账号，员工包括管理员与业务员。

兼容扩展：

- `GET /api/v1/staff/inquiries` 增加 `queue=all|followup|stale`，默认 `all`，与现有搜索/状态过滤相交。待办自动按登录角色限定负责人，并按更新时间升序排序。
- `GET /api/v1/quotes` 增加 `due=true|false`，默认 `false`，到期过滤与仪表盘共用截止规则并按到期时间升序。原状态/搜索/权限仍有效。
- 未新增表、字段或迁移；聚合使用同一只读数据库快照，仅返回有界摘要，不传输全量单据明细。
