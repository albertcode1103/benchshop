## 3. 技术路线

1. 数据输入层保留旧快照可读，不直接修改历史数据库数据。
2. PDF 展示层使用统一的正数量解析函数；缺失旧字段保持数量 1，显式 0、负数或非法数字视为不可见。
3. 报价金额从完成过滤和设备归属处理后的行集合重新计算，避免隐藏行继续影响总计。
4. 上传文件使用随机文件名和固定 API 前缀；清理前重新扫描颜色、配置、映射覆盖和设备图片四类引用。
5. 设备保存事务完成后才执行候选文件清理；维护命令默认只报告候选，删除必须显式授权。
6. 前端保持现有原生 HTML/CSS/JavaScript 和设计系统，仅做渐进式性能优化与焦点增强。
