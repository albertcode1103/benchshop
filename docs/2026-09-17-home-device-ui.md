## 首页最终布局

- 公司全称从设备介绍标题中拆出，使用独立 `#home-company` 模块，置于左侧顶部，与右侧图片画布顶端对齐。中英文均为 24px，名称较长时允许换行。
- 中文公司名：博特恩检测设备（苏州）有限公司。
- 英文公司名：BOTEN TESTING EQUIPMENT SUZHOU CO., LTD.，全大写。
- 下方 `#home-title` 保留“柴油共轨系统检测设备 / Diesel Common Rail System Test Equipment”，连同描述和浏览设备按钮构成独立介绍区域。公司名称不再通过标题内空行定位。
- 图片下方设备信息分两行：第一行型号，第二行名称，均为 16px。
- 设备图片切换改为 600ms 平滑横向滑动，自动轮播、左右箭头、键盘方向键及触摸切换共用该效果。切换前尝试解码下一张图片，旧图片退出后移除临时节点。
- 沿用每 5 秒轮播、首尾循环及原有悬停/焦点/触摸/页面隐藏/弹层暂停规则；减少动态效果时不自动轮播，手动切换不播放动画。
- 窄屏仍采用上下排列，公司模块位于介绍区顶部，设备画布在介绍区下方。

## 设备页最终字号与密度

| 区域 | 规则 |
| --- | --- |
| 设备概况标题 | 16px |
| 设备描述正文 | 14px |
| 参数表 | 行高 1.4，上下内边距 5px、左右 10px；沿用原表格字号 |
| 颜色、电机、电源、通道基础选择及内部文字 | 14px |
| 设备可选配置标题、固定分类栏及计数 | 14px |
| 当前选配标题栏及按钮文字 | 16px |
| 型号摘要模块及所有内部文字 | 14px |

字号规则限定于标注区域，不据此修改选配产品卡片、购物车或后台表格字号。

## 文件与验证

- `index.html`：拆分公司模块、增加图片视窗、更新首页及组件资源版本参数。
- `js/home.js`：公司名称与介绍文案分别赋值，图片预加载与滑动切换。
- `css/home.css`：公司模块顶部布局、24px 字号、设备信息两行 16px、图片视窗裁切。
- `css/components.css`：设备页标注区域字号及参数行间距。
- `tests/browser_home_autoplay.cjs`：箭头位置检查改为相对固定图片视窗，避免将动画中的图片位置当作画布边界。

轮播增量在 1440、393、320px 三种宽度下通过现有自动播放、暂停、视图切换、减少动态效果及箭头定位专项，测试拦截 API。之后公司模块拆分与字号调整通过 JavaScript 语法（相关脚本）及差异空白检查；尚未对最终布局重跑完整浏览器流程，不能将先前轮播结果等同于最终排版验收。

本批未改 API、数据库或依赖。部署前仍需按实际 Git 差异核对工作区其他改动；本记录不是完整发布清单。部署后建议检查中英文公司名称与画布顶部对齐、桌面/窄屏换行、16px/14px 计算字号、动画首尾循环，以及设备点击导航。
