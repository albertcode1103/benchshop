# 报价编辑器分类标题与滚动上下文

日期：2026-09-13。状态：本机前端已实现并验收，已纳入本次 Git 版本、尚未发布 NAS；未保存、发送或改写真实报价。

## 已实现

- 每台设备保留独立标题，内部增加“基础配置”及各可选配置分类的分隔标题。
- 列头下方固定显示当前设备和分类，例如“设备 1 · BOTEN CR1016 · 共轨喷油器选配套件”。向下或向上滚动时自动切换；进入工具、附件时显示对应分组名称。
- 同型号的不同设备仍按设备归属和序号区分，不合并。新增标题不改变项目顺序、数量、单价、总额或提交字段。
- 分类优先使用业务快照的分类ID及名称；无ID时按已有名称区分，无名称时显示“未分类配置”。不从当前目录推断或覆盖历史分类。
- 添加、删除项目后重新生成分隔标题并更新固定栏；保持现有基础配置锁定规则。

## 滚动与适配

- 桌面使用报价明细列表的独立滚动区；宽度≤600px或高度≤520px时沿用整个中央正文滚动，避免嵌套滚动。
- 列头高度由实际布局测量，固定上下文紧随其下；调整窗口大小后重新计算，关闭对话框时释放监听。
- 高度≤420px时固定上下文压缩为32px单行，隐藏重复列头并保留输入标签，避免挤压键盘聚焦区域。长上下文截断显示，完整文本保留在标题提示中。
- 单价输入框上滚轮滚动当前实际滚动容器，不改变数值。关闭按钮和底部报价操作保持可达。
- 刷新工作台并重新打开报价编辑器后加载新界面；已打开的旧页面不会被自动刷新。
