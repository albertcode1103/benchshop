# BOTEN 业务内容聚合与排序规范

版本：1.2（2026-09-11）
适用范围：用户购物车、后台分享详情、询价详情、报价查看与编辑、相关 PDF 数据准备。

## 1. 目标

同一份业务内容无论从购物车、分享码、询价或报价进入，都必须保持相同的信息顺序、分组名称和数量口径。界面可以因操作目的不同而使用卡片、抽屉、弹窗或表格，但不得重新定义业务排序。

## 2. 一级聚合顺序

固定顺序如下，不受创建语言、当前语言、名称字母或接口返回顺序影响：

1. 设备
2. 维修工具
3. 设备附件

数量为零的一级分组不渲染，不保留空标题或空容器。

## 3. 设备规则

- 每份已保存设备配置是一个独立设备单元，不把两台同型号设备合并。
- 设备按照加入购物车或业务快照中的先后顺序排列，标记为“设备 1、设备 2……”；后续分享、询价、报价和 PDF 保持该序号。
- 每台设备内部顺序固定为：型号与名称、颜色、电机、电源、通道、可选配置。
- 可选配置按后台分类顺序排列；分类内按后台配置顺序排列。
- 报价中的设备基础价格行必须与该设备的附加费、可选配置保持在同一设备组内。

## 4. 工具与附件规则

- 所有维修工具聚合为一个“维修工具”分组；所有设备附件聚合为一个“设备附件”分组。
- 不按加入购物车时间排序。优先使用后台目录分类顺序和项目顺序；缺少排序元数据时使用编号，其次名称，最后使用原始顺序保证稳定。
- 相同业务项目只显示一行，以数量字段表示件数；不得用重复行表达数量。
- 分组标题显示项目种类数，汇总信息显示数量合计。二者不得混用。

## 5. 数量口径

- 设备：按独立设备配置计“台”。
- 工具和附件：按各行 `quantity` 求和计“件”。
- “项目数”只表示不同条目数量。
- 摘要中零数量分组不显示，例如没有附件时只显示“2 台设备 · 5 件工具”。
- 缺少数量字段的旧快照按数量 1 兼容；显式为 0、负数或无法解析为正整数的行必须忽略，不得强制改写为 1。
- 数量为零的设备不显示，其从属配置也不得降级到“其他项目”；报价总计只能基于最终显示的有效行计算。

## 6. 失效与历史数据

- 分享、询价和报价属于业务快照。目录项目后续停用或删除时，历史快照不得被静默移除。
- 能够识别失效状态时，在原位置显示“已失效”标记；仍显示快照中的编号、名称和数量。
- 无法解析类型的历史条目放在末尾的“其他项目”组，并记录诊断信息，不得归入设备组。

## 7. 中英文规则

- 排序依据使用稳定 ID、排序值和编号，不使用翻译后的显示名称。
- 中文和英文只改变标题与内容文本，不改变设备序号、分组顺序和数量。
- 英文缺失不得自动回退显示中文；数据维护界面应提示补齐英文内容。

## 7.1 目录编号与名称展示

- 配置、维修工具和设备附件的业务编号统一使用大写字母与连字符格式；已定义的连字符不得省略，例如 `BT-WB`、`BTE-4240`、`BTC-0001`、`BTK-1001`。
- 后台新增或编辑目录项目时自动规范化已知编号前缀；批量导入也必须走同一规范化规则，并在保存前检查规范化后的编号冲突。
- 中文名和英文名不得以自身编号重复开头；仅清理名称开头的冗余编号，不删除名称正文中具有业务含义的编号引用。
- 网页配置选择、购物车及业务详情采用编号在上、名称在下的层级；PDF 明细的编号与名称使用独立列，不挤在同一单元格。
- 历史分享、询价和报价快照不批量改写，读取和导出时对快照编号及名称执行同样的兼容格式化。

## 8. 实现约束

- 后端保存分享和询价快照时使用统一的规范顺序。
- 后台前端使用统一的 `canonicalCommerceItems` 和 `aggregateCommerceItems` 处理函数，不允许分享、询价、报价分别编写独立排序规则。
- PDF 生成前必须再次使用服务端规范顺序，不能依赖浏览器传入顺序。
- 分享配置 PDF 在用户端和管理后台均不得显示价格；只有正式报价单 PDF 可以显示价格。
- 新增业务类型时必须更新本规范、类型优先级映射和回归测试。

## 9. 验收示例

输入顺序为“附件 A、设备 B、工具 C、设备 A、工具 A”时，展示顺序必须为：

1. 设备 B
2. 设备 A
3. 维修工具：工具 A、工具 C（依据后台目录顺序或编号排序）
4. 设备附件：附件 A

用户购物车、后台分享详情、询价详情、报价编辑和 PDF 的一级顺序必须一致。

## 10. PDF 文档规范

### 10.1 文档类型与价格边界

- 当前配置、已保存配置、批量配置、购物车和分享记录统一使用“配置清单 / Configuration List”。
- 单条询价统一使用“询价单 / Inquiry”。
- 报价统一使用“报价单 / Price List”；三类主标题均为21pt加粗、左对齐，报价草稿名称不替代主标题。
- 配置清单和询价单不得显示价格、价格列或金额；只有报价单显示单价、行小计和合计。删除分组小计展示，其他金额与总额计算不变。

### 10.2 页头与信息模块

- 公司名称随导出语言切换：中文“博特恩检测设备（苏州）有限公司”，英文“BOTEN TESTING EQUIPMENT SUZHOU CO., LTD.”；与地址使用同一文档语言。

- 所有导出 PDF 沿用原版文档蓝色体系：深蓝 `#183B56` 用于表头与重点文字，强调蓝 `#2E75B6` 用于分隔线，浅蓝 `#EAF2F8` 用于分类、信息卡片及小计背景；该规则独立于网站界面的品牌橙色。
- 每页左上角固定使用网站主页 BOTEN Logo（缺失或损坏时报错，禁止文字替代）；右上角依次为公司名称、对应语言公司地址、网址，全部右对齐。地址自动换行并动态预留页眉高度。
- 配置清单显示创建人或分享发送人的姓名、邮箱、电话；空字段不显示。分享导出专用标题为“分享人 / Shared by”；非分享配置保留客户信息标题。
- 询价单显示客户资料、询价状态、创建时间与备注；空备注显示“无备注 / No note”。
- 报价客户资料固定为姓名、电话、邮箱、地址。询价单与报价单隐藏文档信息模块；原业务时间置于首页主标题下方，带询价时间/报价时间及对应英文标签；页眉不重复显示时间或单号。

### 10.3 内容表格

- 每台设备使用独立标题，随后显示已配置的颜色、电机、电源和通道；“未配置”字段不显示。
- 设备可选配置按分类拆分表格，分类标题只显示一次。
- 配置清单和询价单的明细列包含独立编号列、名称和数量；报价单增加单价和行小计。
- 设备 1、设备 2、维修工具、设备附件采用同一 12pt 加粗一级标题样式。可选配置按稳定分类 ID 聚合，不按翻译名称合并；分类与条目按业务快照保存的目录顺序排列。
- 基础供电价格排在可选分类前；旧草稿缺失的分类元数据只允许从来源询价或分享快照补齐，不能用后续变动的目录覆盖历史内容。已发送报价保持不可变。
- 设备基础价格属于对应设备组；维修工具、设备附件和其他历史项目分别成组。
- 表格跨页时重复分类标题与列标题，避免标题与第一条数据分离。
- 设备、维修工具、附件模块间仅保留一行（12pt）间距，取消固定剩余高度预判和末组整表保留；允许明细自然跨页，仅将末条数据与总额行保持在一起，避免前页大面积留白。

### 10.4 页脚与文件编码

- 所有文件页脚统一为左文件编号、中间当前页/总页数、右本次导出时间（Asia/Shanghai、秒精度，同一文件各页一致）。文件编号不加标签前缀，为扩位编号预留独立宽度。
- 公司地址移至页眉：中文为“江苏省昆山开发区马塘路108号”；英文固定两行，第一行“No.108 Matang Road, Kunshan Development Zone”，第二行“Suzhou, Jiangsu, China 215333”，均右对齐。网址同样只在页眉显示。
- 分享配置清单文件名为 `ShareBench-BOTEN{6位分享码}.pdf`；询价为 `RFQ-BOTEN{原单号8位日期}-{至少2位流水}.pdf`；报价（含草稿、个人中心）为 `QUOTA-BOTEN{原单号8位日期}-{至少4位流水}.pdf`。超位不截断，中英文同名。
- PDF 页内文档编号使用对应文件名去掉 `.pdf`；不修改数据库原业务单号、产品编号或来源分享码。缺少标准业务编号时需修复源记录，不生成随机替代编号。
- 购物车确认备注后先创建分享，再从分享快照导出。失败重试复用同一创建请求及分享码，遵守普通用户10份有效分享限额；取消确认不创建。
- 购物车PDF创建分享启用快照去重：在服务端写事务内、配额检查之前扫描本用户有效新旧分享；双语快照、数量、顺序完全相同即复用，不比较购物车行ID或导出语言。保留原备注和有效期，并提示复用；不修改原快照。不同用户、关闭或过期记录不参与匹配。独立“分享”入口暂保持原创建行为。
- 没有业务编号的配置类导出使用一次性 `CFG-YYYYMMDD-HHmmss-XXXX` 编码；该编码仅存在于本次 PDF，不写入数据库。
