## 实现

### 当前轮播规则（唯一现行说明）

- 展示当前语言下全部已启用且导航可见的设备，沿用目录顺序，每 5 秒切换并首尾循环；每台使用其首张图片，缺图采用原占位图。
- 画布只显示图片，下方显示型号和标题；左右按钮位于图片两侧垂直中央。已移除顶部“设备目录 / 页码 / 暂停”整行及相关脚本和样式，目录名称仅作为无障碍标签。
- 支持两侧按钮、键盘方向键和横向触摸滑动；只有一台或没有设备时隐藏箭头。点击当前展示设备进入对应选配页，轮播切换本身不修改选配状态。
- 悬停、设备或箭头获得键盘焦点、触摸操作、离开主页、页面隐藏或弹层打开时暂停；恢复后重新计时 5 秒。减少动态效果下不自动播放，仍可手动切换。滑动后短暂抑制误点击。

### 主页与业务衔接

- 新增设备主展示、维修工具和附件入口；使用目录中的真实图片与语言可见性，图片失败降级现有占位图。
- 抽屉顶部“主页 / Home”带图标和当前状态，设备按钮打开第二层设备列表；修复目录文案依赖按钮位置的问题。
- 普通地址访问主页；刷新及语言切换保持视图，历史返回恢复视图。Logo 与主页按钮回顶但不清空用户数据。购物车编辑仍通过原设备载入流程处理。
- 加载、目录为空、请求失败及重试均有显示；静态主页框架不依赖 API 成功后才出现。
- 按 design-taste-frontend 的品牌保留与主题一致性要求实施，复用产品图片与现有 CSS 令牌，没有引入新框架或生成产品图。
