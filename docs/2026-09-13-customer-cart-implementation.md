## 保存、询价和清空

### 空配置确认

- 根据当前设备有效可选项判断是否为空；颜色、电机、电源和通道等基础配置不计入。
- 没有选中可选项时，先关闭小屏摘要抽屉，取消历史滚动恢复并定位“设备可选配置”。
- 弹窗区分“继续保存”和“继续询价”；取消/Escape 不提交，焦点回到配置区且不滚回摘要。
- 确认后沿用登录及业务流程。询价确认仅打开原询价表单，仍需用户实际提交。
- 购物车整车询价不应用此定位逻辑；已有可选项时不提示空配置。

### 同型号保存

- 新保存前重新读取 `/configs`，按 `snapshot.product.id` 匹配同设备，非按展示文案比较。
- 有重复时提供覆盖、新增、取消；多个匹配项须明确选择目标，不能默认覆盖第一条。
- 覆盖使用所选配置 ID 与版本号执行 PUT；新增执行 POST。读取或保存失败显示错误，不静默改为新增。
- 从购物车“修改”进入时保持更新原配置，不重复询问覆盖/新增。
- 当前为前端检查，不是服务端唯一性约束；多标签或多客户端并发新增仍可能产生同型号条目。

### 清空购物车

- 页头关闭按钮左侧新增清空，中英文适配；空购物车或执行期间禁用。
- 必须确认，复用 `/cart/batch-archive` 移除设备配置、工具和附件购物车条目；取消不请求接口。
- 不删除目录产品、历史询价。失败提示错误，成功重新拉取购物车。

## 分享、个人中心和询价来源

- 窄屏语言按钮仅显示翻译图标；点击当前语言图标可在中英文之间切换，桌面双文字按钮行为不变。
- “查看分享”在打开弹窗及查询后均按当前语言刷新标题、标签、占位提示和操作文字，避免切换语言后保留中文静态文案。
- 分享结果不再显示“设备配置 / Device Configurations”总标题；设备卡显示型号、名称、基础配置和可选项，工具及附件保持分组卡片，并保留失效内容警告和导入限制。
- 个人中心分享卡标题合并为“我的分享 123456 / My Share 123456”，六位分享码使用深橙加粗；更多菜单点击外部收起，删除按钮使用危险样式。
- 用户询价列表中，当前设备来源读取询价不可变快照中的产品型号，显示“设备 BOTEN CR1016 / Device BOTEN CR1016”；详情临时读取失败时回退“当前设备 / Current device”，购物车来源保持“购物车 / Cart”。
- 后台询价列表第一列固定两行：询价单号，以及“购物车 / 设备页”；不再用“含 N 项手动内容”代替来源。后台本轮为中文管理界面。

## 发布检查

本批使用现有 API，无新增数据库字段或迁移脚本。发布前确认目标 NAS 支持配置读取、新增、带版本更新以及批量归档接口；若需 API 或结构升级，须先提醒用户并另行确认发布顺序与备份。禁止将本机调试数据库覆盖到 NAS。

相关代码：`index.html`、`css/components.css`、`js/cart.js`、`js/renderer.js`。实际部署清单应按最终 Git 差异审核，不能直接发布整个混合工作区。
