## 1. 本轮最终业务规则

### 1.1 用户端价格边界

- 用户端页面不显示设备、可选配置、维修工具或设备附件的任何价格。
- 用户端公共产品、目录、购物车和配置接口不返回价格字段。
- 原价格预览区域显示“获取报价 / Request a Quote”和联系销售提示。
- 用户自行导出的配置 PDF 不含基础价、参考单价、金额或合计。
- 数据库、历史快照、后台分享详情、后台分享 PDF 和正式报价 PDF 继续保留价格。
- 后台价格预览及目录参考价接口仅允许管理员或业务员访问。

### 1.2 统一选择与购物车

- 首页顶部选择器统一包含设备、维修工具和设备附件。
- 工具或附件无需先选择设备，可独立浏览、加入购物车、分享及导出无价配置 PDF。
- 购物车可混合设备配置、维修工具和附件，支持批量勾选、分享、导出和删除。
- 从购物车修改设备配置时，恢复原快照并自动回到设备编辑视图；保存时覆盖原记录。

### 1.3 后台目录和报价

- 配置目录保持“可选配置、维修工具、设备附件”三个顶层。
- 目录参考价是后台报价默认单价；无价格项目可保留为 0。
- 分类内项目支持上下移动，保存后用户端按同一 `sort_order` 展示。
- 普通可选配置不支持设备专有标注。
- 英文内容不允许回退中文；缺少英文时使用翻译草稿状态并等待人工校对。
- 后台分享详情和报价兼容没有设备、只有工具或附件的分享。

## 2. 数据与架构基线

- 活动数据库迁移版本：`20260904_0014`。
- 迁移采用新增表和兼容读取，不删除旧表、旧字段、历史分享、历史报价或快照。
- 设备编辑使用 V2 原子保存和版本号冲突保护。
- 混合文档使用 `device_config`、`tool`、`accessory` 三种条目类型。
- 客户响应在序列化边界递归删除价格字段，后台原始数据不受影响。
- 客户 PDF 与后台分享 PDF 共用版式服务，但通过显式 `include_prices` 边界区分。
- 配置排序要求提交分类的完整项目 ID 与版本号，事务内生成连续顺序。
