# BOTEN 网站设计要点

> 状态：现行设计基准（2026-09-12，补齐小屏及低高度适配规则）
>
> 适用范围：`/` 用户端、`/account/` 个人中心、`/admin/` 管理后台、后续新增页面、弹窗、抽屉、PDF 预览页。
>
> 使用规则：开始任何 UI 改动前先读取本文件；若必须偏离，应先更新本文件并说明原因。不得以单个页面临时样式取代此规范。

设备、工具和附件的业务聚合、排序与数量口径统一遵循 [BOTEN 业务内容聚合与排序规范](./commerce-content-aggregation-standard.md)，视觉层不得自行改变该顺序。

## 1. 设计气质

BOTEN 的界面是**工业设备配置工具**，不是营销型网页。整体应保持：清晰、克制、稳重、可快速录入与核对。

- 大面积使用白色或极浅灰背景；内容以卡片、表格、细线分区。
- 深墨色承担主要文字、已选状态和强对比；暖橙色仅承担品牌、选中、重点与警示提示。
- 视觉层级依靠字号、字重、留白、边线，不依赖大面积渐变、厚阴影或高饱和多色。
- 页面每一个区域应有明确的“标题 → 内容 → 操作”顺序；操作不应挤入标题文本或数据内容。

## 2. 基础设计令牌

### 配色

| 用途 | 用户端 | 后台 | 使用约束 |
| --- | --- | --- | --- |
| 主背景 | `#f7f8fa` | `#f4f5f3` | 页面底色、低强调分区 |
| 卡片/输入背景 | `#ffffff` | `#ffffff` | 内容面板与表单 |
| 主文字 | `#1a1a1a` | `#17202a` | 标题、正文、已选深色状态 |
| 次级文字 | `#666666` | `#66717e` | 说明、标签、辅助信息 |
| 边线 | `#e5e7eb` | `#e2e6ea` | 默认 1px 分隔、卡片边框 |
| 品牌橙（装饰/选中） | `#f36b21` | `#f36b21` | 选中描边、徽标、图标、细线 |
| 深橙（可读文字/主操作） | `#a83e00` | `#a53d00` | 白底文字、主按钮背景、重点金额 |
| 浅橙背景 | `#fff4eb` | `#fff1e8` | 选中卡片、提示、轻量强调 |
| 成功 | `#10b981` | `#16855b` | 成功状态与健康标识 |
| 危险 | `#ef4444` | `#c43d3d` | 删除、失败、不可逆操作 |
| 后台导航 | — | `#182028` | 左栏、登录品牌区 |

**规则**

- 小字号文字、可点击文字和主按钮必须使用深橙，不得只用鲜橙。
- 正常文字不使用浅灰 `#999`；辅助文字至少使用上表“次级文字”。
- 一块内容只使用一个主强调色；成功和危险色只表达状态，不作为普通装饰。
- 新颜色优先映射为已有语义令牌；没有明确语义不得新增色值。

### 字体与数字

- 全站字体：`HarmonyOS Sans`，系统字体栈只作为加载失败后的后备。
- 正文基准：16px / `line-height: 1.6`；卡片/表格正文可为 13–15px，但不低于 13px。
- 辅助标签、表格表头、状态徽章：12px；仅英文 eyebrow 可为 11–12px。
- 页面一级标题：用户端 `clamp(28px, 4vw, 40px)`，后台约 25px；区域标题 20px；子标题 14–16px。
- 字重只使用 400、500、600、700、800；避免 650、750、850 等不稳定字重。
- 设备型号、编号、价格和表格数字使用 `font-variant-numeric: tabular-nums`；金额始终右侧对齐或独立成列。
- 中文标题和字段标题不随中英文内容切换翻译；用户可编辑内容、值、占位示例及用户端文案才随语言切换。

### 间距、边线和圆角

使用 4px 基础步进：`4 / 8 / 12 / 16 / 24 / 32 / 48px`。不使用随意的 5、7、13、19px 作为新的布局间距。

| 场景 | 推荐值 |
| --- | --- |
| 图标与文字 | 8px |
| 同一控件内元素 | 8–10px |
| 表单字段之间 | 10–12px |
| 卡片内边距 | 16px；重点卡片/桌面面板 20–24px |
| 区域之间 | 24px；页面大区块 32–48px |
| 用户端容器边距 | 桌面 24px；移动端 16px |
| 后台内容区 | 桌面 34px；移动端 14–18px |
| 默认边线 | 1px `--color-border` / `--line` |
| 常规圆角 | 控件 8–9px；卡片 12–14px；大图/主面板 16–24px；徽章 999px |

- 用边线而非阴影定义绝大多数卡片边界。
- 阴影只用于悬浮层、对话框、抽屉和悬停卡片；不可同时叠加粗边线与重阴影。
- 分割线应贴合内容边缘并保留 16–24px 的上下呼吸空间；避免用空白替代必要的层级线。

## 3. 组件规则

### 按钮

- 高度：常规 40px；表单输入 42–46px；表格/紧凑操作最小 36px；图标按钮 40×40px。
- 圆角：常规 8–9px；用户端 `.btn` 可用 12px；不混用胶囊形与普通圆角作为同一级操作。
- 2026-09-13 摘要操作区（最新确认）：保存配置到购物车、联系销售获取报价两个按钮统一 16px 圆角、14px 字号，桌面与小屏一致；覆盖此前摘要按钮的 8px 约定，不改变购物车底部报价按钮或操作逻辑。
- 2026-09-13 设备配置区字号：基础配置/可选配置区标题 14px，基础选项文字与分类页签 12px；分类正文标题及全选按钮 14px、分类描述 12px；配置卡片编号 12px、名称 14px、专有备注仍为 12px。中英文、桌面与小屏一致；不改右侧摘要、工具/附件商品卡片。

### 用户端滚动规则（2026-09-13）

- 从产品目录主动进入设备、工具或附件回到页面顶部；取消目录不改变当前位置。
- 修改颜色、基础选项或选配仅更新内容，不回顶、不自动收起设备概况；分类页签仅在自身容器内横向定位。重绘保留键盘焦点，不因恢复焦点滚动整页。
- 主动点击配置快捷标签或购物车编辑，定位到目标并避让实际页眉高度；尊重减少动态效果设置。
- 关闭目录、购物车、摘要及嵌套确认窗时恢复焦点但不滚动背景；小屏摘要提示只调整正文容器滚动位置。
- 首次进入及普通刷新从顶部开始；浏览器后退/前进恢复各历史条目的位置，BFCache 返回不强制置顶。
- 切换语言且设备/目录未变，按原浏览区域锚点恢复（文字换行后的像素位置可变化）；原设备在新语言隐藏而切换到其他设备时回顶。
- 初始化恢复允许最多 3 秒布局稳定窗口；用户滚轮、触摸、点击、键盘或主动导航立即终止恢复，不与操作争抢滚动。真实手机键盘、安全区及浏览器历史缓存行为仍须真机验收。

### 用户端深色模式（2026-09-13）

- 首页账号菜单的退出登录上方提供“深色模式 / Dark Mode”开关，语义为 `menuitemcheckbox`，支持方向键导航、空格/回车切换及 Escape 关闭；切换不刷新或关闭菜单。
- 无偏好时跟随系统；手动选择写入当前 origin 的 `localStorage.boten-theme`，之后优先使用用户选择。首页与个人中心共享，同源其他标签同步；未登录仍沿用原登录入口。首屏在样式加载前应用主题，存储不可用时本次会话仍可切换。
- 深色样式独立置于 `css/theme.css`，仅用户首页和个人中心引入。复用颜色变量，覆盖表单、提示、菜单、抽屉、选中和焦点状态；保留尺寸、交互和滚动规则。
- 不对产品图做反色；Logo 保留原图并使用浅色底托。品牌橙色与蓝色报价入口保留，确保文字可辨认。后台不引入主题脚本/样式；深色变量只用于 screen，不修改浏览器打印或服务端 PDF。
- 验收：中英文、1280/393px 下系统跟随、手动切换、刷新持久化、菜单键盘、选配和表单草稿保留、个人中心继承、三类弹窗、打印及工作台不受影响，见 `tests/browser_theme.cjs`。截图位于本机 `tmp/theme-review/`；API 全部 fixtures 拦截，无正式写入。真机、所有业务弹窗状态及全站深色对比度专项仍待补验。
- 主操作：深橙实底白字，每个操作区最多一个，例如“保存配置到购物车”“保存报价”。
- 2026-09-11 用户指定例外：设备选配摘要和购物车底部的“联系销售获取报价”统一为 `#2563EB` 蓝底白字、8px 圆角，悬停 `#1D4ED8`、按下 `#1E40AF`；仅限这两个入口，其他按钮及 PDF 不改色。购物车底部第一行等宽并排“导出 PDF / 分享”，第二行为通栏报价按钮。
- 次操作：白底细边深色文字，例如“自动填价”“导出 PDF”。
- 弱操作：浅灰背景或透明文字按钮，例如“取消”“返回”。
- 危险操作：仅删除、归档、关闭分享等不可逆动作使用红色，并先出现确认弹窗。
- “更多”菜单收纳低频操作；菜单中每项独占一行，最小高度 36px。
- 所有按钮需具备 hover、disabled 和 `:focus-visible` 状态；加载时只禁用被提交按钮并显示“保存中…”。

### 卡片、配置项和表格

- 2026-09-13 最新确认：购物车滚动列表 `#cart-items` 全部文字统一 14px，替代此前 12px，包括设备/工具/附件标题、型号、名称、配置、数量及列表内按钮；中英文和各屏幕一致。不改变颜色、点击区域、页头/页脚或详情弹窗字号；工具/附件编号使用 700 字重。
- 工具/附件页面右侧购物车汇总：型号和名称均 14px；型号使用深橙、700 字重，名称保留次级文字色、400 字重。
- 设备选配摘要移除“型号 / Model”独立标签，保留型号、名称及基础配置。颜色、电机、电源（如有通道也包含通道）放入型号模块，左标签右内容、全部 14px、行间紧凑；桌面基础信息不随可选项目列表滚动，小屏仍使用统一可滚动正文。
- 购物车关闭按钮左侧提供清空操作，须确认后批量移除购物车项目；空购物车禁用。空态隐藏列表占位，提示在页头与页脚之间居中。
- 无有效可选配置时，保存或当前设备询价先关闭小屏摘要抽屉、定位可选配置区并确认；取消不提交。基础配置不计入可选项，确认询价仅继续原询价表单，不直接发送。
- 新保存前读取已保存设备配置；相同产品 ID 提供覆盖、新增、取消。多个同型号配置必须明确选择覆盖目标；覆盖携带版本号，失败不自动改为新增。购物车编辑模式继续更新原条目。
- 窄屏语言切换使用单个翻译图标，圆形点击区域至少 42px；点击切换当前语言。桌面继续显示“中文 / EN”。产品导航中主页与三类产品入口使用一条低对比度主题边线分组。
- 分享查看结果直接排列设备、维修工具和附件购物车式卡片，不增加“设备配置”总标题；语言切换后弹窗标题、字段和按钮不得保留上一语言。个人中心分享标题格式为“我的分享 / My Share + 六位分享码”，分享码深橙加粗。
- 个人中心记录的“更多”使用次级按钮外观，点击外部或 Escape 收起；删除操作使用与购物车一致的危险按钮。询价来源在用户端当前设备项中追加快照型号，后台列表用第二行简写“购物车 / 设备页”。

- 选配模块标签的已选数量复用购物车徽章样式：0 件深灰底白字，大于 0 件品牌橙底白字，实时更新；仅数量徽章使用此规则。
- 工具和附件目录的分类列表与筛选区左右对齐：桌面 24px、手机 16px 内边距，分类之间 16px；移动端操作区可换行，不改动折叠与管理行为。

- 配置/设备卡片：白底、1–2px 边线、12–16px 圆角。选中态使用橙色边线 + 浅橙背景 + 小型对勾，不能只改变颜色。
- 用户端可选配置固定双列；手机端仍保持双列，文字允许换行，图片保持 `contain`。
- 用户端设备选配卡片的编号及名称统一 14px，设备专有备注 12px；中英文、桌面和手机一致，保留原字重、颜色与备注橙色标线，不套用到基本选项、工具/附件或业务详情。
- 用户端工具及附件卡片内容区按用户最新指定：编号 14px、名称 14px、描述/备注 10px（描述字号为本组件的明确例外），桌面与手机、中英文及选中态一致；不调整数量控件、按钮或设备选配卡片的 12px 专有备注。
- 专有标注使用左侧 3px 橙色细线与浅橙背景，正文加粗但可换行；不额外重复“机型说明”等标签。
- 表格表头为浅灰底，12px、600–700 字重；编号、日期、金额、操作禁止换行，其余长文本允许换行或截断。
- 表格操作采用最小 36px 的可点击范围；超过 3 个操作收入“更多”。
- 设备目录排序模式使用“序号输入＋插入”，输入 1 起的目标位置，Enter 与插入按钮行为一致；先预览顺移结果，再保存或取消。排序模式单独预留操作列宽度，不挤压或遮挡原表格字段，普通浏览模式保持原列宽。
- 目录是否显示只由设备启用状态和当前语言范围决定，不以配置数量过滤设备。缺少可用颜色/基本配置时，设备标题附近及摘要操作区显示待完善提示，禁用当前设备保存和询价，保留目录浏览及历史记录。
- 空状态使用居中次级文字与清晰下一步，不以空白表格代替。

### 图片缩略图与预览框

- 产品导航目录项与设备项使用文字左侧 48×48px 方形缩略图，保持 `contain`。设备项优先取设备图片列表首图，无列表图片时回退默认颜色图；目录项取当前语言下正常排序的首个可见产品首图。首项缺图不能跳取后续产品，空目录、图片加载失败使用统一占位图；保留导航、选中标记和键盘行为。
- 后台设备颜色图片预览框统一使用横向 `2:1` 比例；桌面端最大宽度约 280px，窄屏允许等比例缩小。
- 缩略图必须完整显示原图内容：保持图片原始比例、水平和垂直居中，使用 `object-fit: contain`，不得使用 `cover`、拉伸或裁切。
- 方图、竖图放入横向预览框时允许左右留白；超宽图允许上下留白。留白是保证内容完整的正常结果，不能为了撑满容器牺牲图片内容。
- 预览框使用浅灰中性背景和 8px 安全内边距，使透明 PNG 的设备轮廓保持可见。
- 固定比例容器内的图片应使用独立定位层约束：预览框 `position: relative`，图片在内边距范围内绝对定位并设置明确宽高，再使用 `contain`。禁止只使用 `width: auto`、`height: auto` 和百分比 `max-height`，这会让正方形图片按自身高度撑开后被横向容器截断。
- 上传后预览、重新打开编辑窗口和不同屏幕宽度必须采用相同适配规则；不得仅修复初始图片而遗漏上传后生成的缩略图。
- 验收时至少覆盖正方形、横向和竖向图片，确认设备四边均完整可见，且图片没有形变。
- 图片元素必须输出数据中保存的原始宽高；旧数据没有尺寸时使用固定比例占位，避免加载时布局跳动。
- 图片说明优先使用当前语言，缺失时可回退另一语言，最终使用有业务含义的通用替代文字。

### 焦点与移动端键盘

- 两级产品导航在小屏重叠时，被遮挡层使用 inert，不进入 Tab 顺序；返回及宽度断点切换及时恢复可见焦点，空目录仍可聚焦关闭按钮。桌面并排时保留两层可操作性。
- 排序等局部重绘须将焦点移至下一步控件：开始到序号、取消/成功到入口、失败到重试；异步完成不得抢走用户已主动移动的焦点。
- 可点击的搜索结果、图片缩略图和排序按钮必须保留高对比 `:focus-visible` 边框，不能只用背景色表达焦点。
- 搜索弹窗不得使用 HTML `autofocus`。桌面端可在弹窗显示后主动聚焦，窄屏端保持未聚焦，避免软键盘遮挡内容。
- 弹窗页头、页脚吸附时，内部滚动区需要保留焦点滚动空间，键盘焦点不得被吸附区域遮挡。

### 折叠标题栏

- 后台的基本配置组、可选配置分类和配置目录分类统一使用“整块左侧标题区域”为折叠按钮；右侧添加、编辑、勾选等操作保持独立，不能触发折叠。
- 折叠按钮必须使用原生 `<button>`，支持点击、触控、Enter 和 Space，并同步 `aria-expanded`；标题文字与标题栏空白区域均属于同一点击范围。
- 箭头统一使用 36×36px 圆角矩形点击提示框，箭头由 CSS 线条绘制并以绝对定位居中，不使用字体字符，避免 HarmonyOS Sans 或系统字体基线造成偏移。
- 展开状态箭头向下，折叠状态箭头向右；hover、`:focus-visible` 和减少动态效果遵循全站按钮规则。
- 分类重新渲染或切换中英文后必须保留折叠状态，不得出现内容仍占高度、标题栏误触或下一分类遮挡操作的问题。

### 表单、对话框和抽屉

- PDF语言选择使用独立紧凑弹窗，宽度最多400px、高度随内容；中文版/English原生单选并排，底部右对齐取消/导出。不得复用设备编辑窗的固定高度；支持方向键选择、Escape和关闭后焦点恢复。

- 后台字段标题固定中文、左列对齐，推荐标签列 130–150px，右侧输入区域等宽对齐；移动端切为“标题在上、输入在下”。
- 输入框保持白底、1px 边线、42–46px 高度；文本域仅在描述类字段使用，短描述默认单行高度。
- 输入获得焦点：深橙边线 + 浅橙/深色可见焦点环；错误使用红色边线与字段下方可行动提示。
- 设备编辑底栏采用专用发布设置组件：目录语言与总启用开关靠左、取消/保存靠右，小屏可换行。复选框本体 18px，触屏标签点击区至少 44px；不得继承文本输入框的全宽/固定高度。页头编辑语言与底栏显示语言保持独立。
- 复杂编辑弹窗采用固定头部与底部，只有中间内容区滚动，并设置 `overscroll-behavior: contain`。
- 小屏已选配置抽屉（<1024px）采用固定标题与底部保存/询价两个按钮，中间型号、配置及状态提示独立滚动；使用动态视口最大高度，低高度扩大到视口减 16px，底部预留安全区。错误提示自动滚入正文可见区域，不将长提示放在固定操作区挤占按钮；桌面摘要布局保持原样。
- 抽屉右侧进入，桌面宽度约 610–680px，移动端全宽；底部操作栏固定，遮罩统一使用深色 46% 透明度。
- Toast 位于右下角（移动端保持安全区），层级高于弹窗内容；文案包含结果与下一步，而不是只显示“Object”或“失败”。
- 基本配置编辑行采用分层布局：选项名称输入框独占首行；价格、状态勾选和排序/删除操作位于下一行。桌面可多列，中屏最多两列，移动端单列，禁止依靠超宽固定列把输入框和勾选项挤在同一层。
- 设备可选配置卡片的信息顺序固定为“编号 → 名称 → 设备专有标注”；编号沿用现行深橙色和等宽数字，专有标注仅属于当前设备与配置的关联数据，不覆盖配置目录的通用名称、描述或备注。

### 导航与响应式

- 从产品导航选择设备、维修工具或附件后，待内容切换和焦点恢复完成，页面立即定位到最顶部；不只滚到模块标题，不改变购物车数据。关闭/取消目录保留原滚动位置，设备内部选配标签仍沿用局部定位。
- 用户端：64px 顶栏、1440px 最大内容宽度、设备选择栏后使用细分割线；1024px 以下避免导航文字挤压，优先切为图标/抽屉导航。
- 后台：深色左栏 250px，桌面顶栏 78px；小屏改为抽屉侧栏，内容留 14–18px 边距。
- 主要断点：`900px`（双栏转单栏）、`700px`（后台表单）、`640px`（用户端控件压缩）。新组件优先复用这些断点。
- 宽度断点外同时覆盖 `max-height: 520px`：横屏和低高度窗口不能仅依据宽度沿用桌面固定布局。报价编辑继续使用原有 `600px` 宽度断点；不统一重排已正常显示的页面。
- 不用横向滚动完成常见操作；表格、长配置列表和参数表是例外，必须带容器滚动与完整内容可读性。

### 账户菜单、个人中心与客户分享

- 登录后的头像使用依附于触发按钮的小型菜单，宽度约 280px；菜单项目最小高度 40px，并支持方向键、Home、End 和 Escape。关闭后焦点返回头像按钮。
- “管理后台”只对管理员和业务员显示；权限判断以 API 返回角色为准，CSS 隐藏仅用于避免加载闪烁，不可替代服务端鉴权。
- 个人中心使用独立页面和分级导航，每次只显示一个内容面板。桌面保留左侧账号摘要和分组导航；≤900px 改为顶部账号摘要（姓名、联系方式、退出登录）与两组三列导航，六个入口直接可见，不采用横向滚动标签或隐藏业务入口。中文及英文长标签可换行，选中态同时使用边线与浅橙背景，点击区至少 44px；未读报价徽章保留。顶栏继续保留 Logo、双语切换和主页。
- 个人中心窄屏表单上下排列，输入控件及日期框 `min-width: 0`；业务筛选先搜索、再状态/记录、最后筛选操作，记录按钮允许换行。横屏低高度不固定整块导航，页面自然纵向滚动；不让导航遮挡内容或键盘焦点。
- 个人中心顶栏 <900px 与主页保持圆形控件语言：语言只显示一个 44px 圆形“中 / EN”按钮，点击切换另一语言；主页为 44px 圆形房屋图标，保留真实链接、可访问名称与焦点环。桌面保留双语言按钮及主页文字，断点切换同时更新语言按钮的可访问提示。
- 普通资料与登录凭据分开保存。姓名、性别、生日保存后留在当前页；不再显示个性签名输入，历史数据保留。地址作为联系方式附加信息独立保存，不退出登录；邮箱、国家、手机号或密码修改成功后清除当前会话并要求重新登录。
- 桌面资料表单采用 140px 标签列与弹性输入列，700px 以下转上下排。报价客户信息通过单一弹窗选择、自动填充和编辑四字段，主页面仅显示紧凑预览；保留原有字号、品牌色与按钮体系。
- 我的业务允许搜索、筛选和恢复已隐藏记录；不物理删除分享、询价或报价快照。分享“删除”同时关闭分享码、释放有效分享名额；恢复记录不自动重新开启。询价和报价的列表隐藏仍不改变业务处理状态。普通用户的有效分享上限为 10 份，创建和重新开启均由服务端校验。
- 个人中心的业务记录与资料表单分级显示。“我的分享”和“我的报价单”使用独立面板；新报价同时使用文字状态、浅橙背景和数量徽章表达，正式报价详情允许显示价格。
- 分享和报价详情使用宽版只读对话框；桌面端信息行左右对齐，手机端允许自然换行。长列表只滚动对话框中央内容，下载等操作固定在底部。
- 客户分享预览必须先显示设备、维修工具、设备附件的可用状态，再允许导入。已删除、已停用、目录类型变更或选配规则变更的内容使用红色边线和明确原因标注，且不得静默加入购物车。
- 分享中的可用内容采用一次事务导入，并使用幂等键防止重复点击产生重复配置。部分失效时按钮文案改为“加入可用内容”，完成后明确说明已跳过失效项目。
- 客户之间查看分享时不得返回价格、报价、分享者邮箱或手机号；后台分享与报价链路继续使用原有员工权限接口。

## 4. 动效、无障碍与国际化基线

- 动效仅使用 `opacity`、`transform`、`border-color`、`background-color`，时长 150–250ms；禁止 `transition: all`。
- 必须支持 `prefers-reduced-motion`；减少动态时停用平滑滚动与位移动画。
- 所有可操作元素必须有明显 `:focus-visible` 焦点环；图标按钮必须有 `aria-label`。
- 所有表单控件必须有标签或 `aria-label`；异步提示使用 `aria-live` / `role="alert"`。
- 图片声明 `width` 与 `height`；首屏设备图高优先级，非首屏缩略图懒加载。
- 中英文模式下品牌名、型号、编号、配置代码使用 `translate="no"`；日期、数字和货币通过 `Intl` 输出。
