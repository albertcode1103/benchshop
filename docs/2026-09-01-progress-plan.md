## 新增执行计划：配置目录折叠

### 现状与目标

- 改为类似设备编辑配置模块的方式：点击分类标题及其左侧空白区域即可展开/折叠；右侧的“添加配置”“更多”等操作不触发折叠。

### 实施方案

1. 将每个分类标题的名称、说明和空白区域封装为独立的可访问折叠按钮，覆盖标题栏左侧剩余宽度；保留右侧统计和操作区。

3. 从“更多”菜单移除折叠入口，避免同一功能有两个位置；菜单仅保留编辑分类等管理操作。
4. 将已折叠的分类 ID 保存到浏览器本地存储；刷新、切换目录语言、重新加载数据后恢复状态。分类删除时自动忽略失效 ID。

## 新增执行计划：设备与配置目录 Excel 模板

### 推荐交付形式（已按评审补充）

- 在后台增加“导出 Excel”和“导入更新”入口，下载一个 `.xlsx` 工作簿，包含“设备目录”“配置目录”“电机价格”“设备参数”四张工作表；这样设备基础资料、配置字段、电机组合价格和参数表可以一次维护。
- 导出内容始终来自当前数据库，保证编号、型号和可编辑字段与后台一致。

### 模板字段与匹配规则

| 工作表 | 不可修改的匹配列 | 可维护列 |
| --- | --- | --- |
| 设备目录 | 设备型号 | 中文/英文名称、中文/英文描述、人民币参考价、美元参考价、启用状态 |
| 配置目录 | 配置编号 | 分类编号/名称（只读辅助）、中文/英文名称、中文/英文描述、备注、人民币参考价格、美元参考价格、启用状态 |
| 电机价格 | 设备型号 + 电机配置编号 | 人民币基础价、美元基础价 |
| 设备参数 | 设备型号 + 参数稳定记录 ID | 中文/英文项目、中文/英文数据、排序号 |

- 导入只更新数据库中已存在的设备型号和配置编号，不创建、不删除、不移动分类，也不修改图片和机型映射；电机价格必须匹配已存在的设备/电机组合，参数表只更新已存在参数行，新增参数通过后台编辑完成。
- 保留双语字段；普通空白单元格视为“不修改”，如需清空内容使用约定值 `__CLEAR__`，避免 Excel 自动去除空值造成误清空。价格必须为不小于零的数字。

### 后端与交互方案

1. 已加入受现有目录管理权限保护的 `.xlsx` 四表模板导出接口；读取、校验预览、确认导入仍需在依赖可安装后补齐，导入提交前展示四张表各自的变更摘要。

## 新增执行计划：按电机配置确定设备基础价格

### 现状与结论

- 用户端的 `motor` 已是单选分类；每台设备可以提供多个可选电机，但当前设备基础价格只有一组人民币、美元固定值。
- 现有报价创建会直接使用配置快照中的设备固定基础价，因此无法反映用户实际选中的电机。
- 推荐将价格维护为“设备型号 × 电机选项”的组合价格，而非给全局电机配置设置统一价格；同一电机在不同设备上的基础价可独立维护。

### 数据与后台维护方案

1. 新增设备电机基础价表：以 `product_id + motor_option_id` 唯一匹配，保存 `base_price_cny` 与 `base_price_usd`；使用迁移建立外键和唯一约束。
2. 设备编辑卡片的电机分类中，每个已勾选电机显示“人民币基础价、美元基础价”两个输入框；没有填价的已勾选电机明确提示“未设置基础价”。
3. 保留设备现有 `base_price`、`price_usd` 作为历史配置/旧数据回退值；新设备或新电机组合必须填写两种币种基础价后才能用于报价。
4. 后端保存设备配置时校验：每个设备至少映射一个电机；电机在用户端只能选择一个；已映射电机的价格不得为负数。业务员和管理员均沿用现有目录管理权限维护。

### 配置、报价与历史一致性

1. 保存、分享或生成配置快照时，必须从单选的电机中读取该设备电机组合价格，并将人民币、美元基础价及电机编号一并固化到快照的设备信息。
2. 创建报价时，设备基础行读取快照中已选电机的对应币种价格；电机只作为设备规格显示，不再额外计为一个配置配件价格。
3. 报价币种切换时，基础行在人民币、美元固化价格间切换；生成的 PDF 保留当次报价已保存的价格，不受日后目录改价影响。
4. 缺少电机选择或组合价格时，阻止保存分享/创建报价，并定位到电机配置或价格设置处；对既有历史配置继续使用旧设备基础价回退，保证可查看、可下载。

### 验收与测试

- 同一设备选择不同电机后，配置快照和新建报价的设备基础行分别显示正确 CNY/USD 价格。
- 同一电机用于不同设备时，报价各自读取对应设备价格。
- 电机无法多选；未选择或未设价格无法生成新报价；已有报价价格不随目录修改而改变。
- 覆盖迁移、权限、价格校验、快照固化、双币种报价、PDF 内容与旧快照回退的自动化测试。
