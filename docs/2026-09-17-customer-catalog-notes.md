# 用户端目录备注隔离（2026-09-17）

## 显示规则

配置目录、工具、附件选项卡片的文字内容为编号、名称、描述。目录备注（含中英文备注和设备专属备注）仅供工作台查看，不出现在用户端卡片、购物车详情中，也不参与用户端工具/附件搜索。描述为空时不再回退使用备注。

客户自行填写的分享备注、询价留言属于业务内容，继续保留。本次不修改数据库中的备注及历史快照，工作台原有备注编辑、查看能力保留。

## 实现

- 用户端移除配置备注映射与渲染，删除工具/附件的备注描述兜底、搜索字段及购物车备注展示。
- 客户响应过滤器在产品、新旧配置、工具/附件、购物车、分享及询价快照中识别目录选项，递归移除内部备注字段。保留分享本身的客户备注；不修改底层仓储对象。
- 更新四个用户端脚本缓存版本。即使连接旧 API，页面也不渲染目录备注。

## 验证与发布边界

- `tests/test_customer_catalog_notes.py`：模拟仓储的 HTTP 响应验证，覆盖三类目录、新旧产品接口、中英文和历史快照；确认源数据及客户分享备注保留。
- `tests/browser_customer_catalog_notes.cjs`：隔离浏览器使用含备注的旧 API 格式数据，覆盖三类目录的中英文卡片、空描述、备注搜索及购物车详情。
- 前端契约及隔离后端的备注保留、客户询价过滤回归。

仅本机代码与隔离验证，未向 NAS 写入测试数据或部署。当前本地 8082 若仍代理 NAS 旧 API，只能立即验证前端隐藏；网络响应中的备注隔离需发布兼容后端后生效。正式发布应先更新 API，再更新前端，无数据库迁移。

## 工作台快速查看备注

配置目录、工具、附件列表的参考价格统一改为数字在左、货币符号在右。每条记录在两行货币符号右侧共用一个问号按钮，悬停、键盘聚焦或点击即可查看中英文共用的目录备注；空内容显示“暂无备注”。支持 Escape 关闭、长备注换行与滚动，提示框定位于视口内，避免被列表裁切。

本项仅更新工作台脚本与样式，无 API 或数据变更。隔离浏览器验证三类目录 × 中英文、数字/符号位置、悬停/聚焦/Escape、空备注、HTML 文本转义及 390px 长备注边界通过，全程拦截 API 写入。

## 信息备注统一编辑

配置、工具、附件编辑器移除原中英文备注字段，在“参考价格”与“显示设置”之间增加独立“信息备注”模块，说明为“可填写该产品的包装尺寸与重量等信息，仅在工作台中查看”。语言切换不隐藏或更换该字段，自动翻译不再处理备注。列表问号使用同一内容。

兼容现有接口：保存时将同一内容写入原 note_zh 与 note_en 字段，无迁移。历史数据优先读取原中文备注，中文为空时读取原英文备注；打开编辑器不会自动改写数据。三类编辑器的模块顺序、单字段、语言切换保留输入、提示一致及模拟保存双字段一致已通过隔离浏览器验证。未修改 NAS 数据或部署。
