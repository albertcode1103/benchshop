# 2026-09-09 开发检查点

## 1. 检查点目标

本检查点收口分享、询价、报价协作流程、后台目录编辑体验、设备图片管理和统一 PDF 输出。工作范围仅包含开发、调试、自动化验证、项目文档与 Git，不包含 Albert-NAS、ECS 或生产环境部署。

## 2. 已完成的业务能力

### 分享、询价与报价

- 分享记录和询价记录统一显示客户、内容摘要、处理状态和关联报价信息。
- 管理员和业务员均可查看全部分享与询价；业务员只能读取自己的报价，管理员可读取全部报价。
- 同一分享或询价允许不同业务员分别报价；本人重复报价会复用或确认进入已有有效报价，避免重复业务单。
- 分享、购物车、询价和报价保留来源关系、设备归属、目录状态与不可变业务快照。
- 报价支持客户资料、报价人资料、币种、有效期、设备配置、工具和附件的增删改及数量、价格编辑。
- 注册客户可以接收并查看有效报价；手工填写的非系统客户只允许保存与导出 PDF，不作为站内发送对象。

### 后台与目录管理

- 后台侧边栏支持完整模式与图标模式切换，并保留工作台语义。
- 分享记录、询价列表和报价管理统一列表信息密度、客户三行资料、响应式列宽和窄屏横向滚动策略。
- 分享与询价详情采用统一的信息卡片、设备摘要和配置聚合布局，未配置设备字段不显示。
- 报价编辑器重新整理客户选择、手工客户、添加项目、设备分组、数量和价格编辑布局。
- 设备目录支持设备图片上传、预览、删除和排序；外观颜色编辑器统一字段层级与操作按钮。

## 3. PDF 统一规范

- 七类入口统一使用服务端 PDF 生成器：当前配置、已保存配置、批量配置、购物车、分享记录、询价单和报价单。
- A4 文档统一使用 HarmonyOS Sans、BOTEN Logo、公司名称、品牌色和三段式页脚。
- 固定标题为“配置清单 / Configuration List”“询价单 / Inquiry”“报价单 / Quotation”。
- 服务端按“设备 → 维修工具 → 设备附件 → 其他项目”重新聚合，设备配置继续按后台分类顺序分组。
- 配置与询价文档仅显示序号、名称和数量；报价文档增加单价、小计、分组小计与总计。
- 分享使用分享码，询价使用询价单号，已发送报价使用正式报价单号，草稿使用 `DRAFT-` 编码，无业务编号的配置导出使用一次性 `CFG-` 编码。
- 详细规则以 [`commerce-content-aggregation-standard.md`](commerce-content-aggregation-standard.md) 第 10 节为准。
